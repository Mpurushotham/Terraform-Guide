## Terraform DevSecOps Documentation

This documentation covers standards, templates, examples, CI/CD, policy-as-code, testing, governance, cost controls, and automation for Terraform projects, aligned with DevSecOps best practices.

### Audience
- Platform engineers building reusable modules
- Application teams consuming modules
- Security and compliance stakeholders

### Quickstart
1. Adopt standards in `docs/standards.md`.
2. Use the module template in `docs/module-template.md`.
3. Follow CI/CD guidance in `docs/ci-cd.md`.
4. Enforce policies from `docs/policy-as-code.md`.
5. Add tests per `docs/testing.md`.
6. Implement governance and cost controls from `docs/governance-cost.md`.
7. Automate docs with `docs/automation.md`.
